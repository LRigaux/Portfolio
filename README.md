# Portfolio Solo Leveling

Un portfolio professionnel inspiré de l'univers de Solo Leveling, développé avec Next.js, React, TypeScript et Tailwind CSS.

## 🌟 Caractéristiques

- **Design inspiré de Solo Leveling**
  - Système de rangs pour les projets et compétences
  - Animations et effets visuels immersifs
  - Interface utilisateur adaptative avec thème clair/sombre
  - Particules magiques et effets de survol dynamiques

- **Technologies modernes**
  - Next.js 14 avec App Router
  - TypeScript pour la sécurité du typage
  - Tailwind CSS pour le styling
  - Framer Motion pour les animations fluides
  - Prisma pour la gestion de la base de données

- **Sections principales**
  - Hero section avec effet de typing
  - Projets avec défilement horizontal et filtrage
  - Compétences avec système de niveau et modal détaillé
  - Technologies avec catégorisation et liens vers les projets
  - Contact avec validation et notifications

- **Interface d'administration**
  - Gestion des projets et compétences
  - Upload d'images et gestion des médias
  - Statistiques et tableau de bord
  - Système de messages et notifications

## 🛠 Installation

1. Clonez le repository
```bash
git clone https://github.com/votre-username/portfolio-solo-leveling.git
```

2. Installez les dépendances
```bash
npm install
# ou
yarn install
```

3. Configurez les variables d'environnement
```bash
cp .env.example .env.local
```

4. Initialisez la base de données
```bash
npx prisma migrate dev
npx prisma db seed
```

5. Lancez le serveur de développement
```bash
npm run dev
# ou
yarn dev
```

## 🎨 Personnalisation

### Thèmes
- **Mode Shadow Monarch (sombre)**
  - Palette de couleurs sombres avec accents bleus et violets
  - Effets de particules d'ombre
  - Animations fluides et transitions douces

- **Mode Chasseur de Rang S (clair)**

- Modifiez `tailwind.config.js` pour personnaliser les couleurs et thèmes
- Ajustez les animations dans les composants individuels
- Personnalisez le contenu via l'interface d'administration
